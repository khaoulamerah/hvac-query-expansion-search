Partie 2 : les méthodes de ranking :

Les deux étapes
Récupération : BM25 avec la requête pondérée garde les 12 meilleurs candidats (20 si la personnalisation est active), à condition que leur score soit > 0.
Re-ranking : la méthode choisie dans la barre latérale réordonne ces candidats.

BM25 : le score de mots-clés
score = Σ  poids_du_mot × IDF(mot) × f × (k1+1) / ( f + k1 × (1 − b + b × longueur/longueur_moyenne) )
(f = nombre de fois que le mot apparaît dans le produit ; k1 = 1,5 ; b = 0,75)
